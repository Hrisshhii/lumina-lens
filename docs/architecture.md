## Responsibilities

Astronomy Engine - Predict visible sky from location, time and
orientation.

Computer Vision - Detect bright stars in the image.

Plate Solver - Match observed star patterns with a catalog.

Knowledge Layer - Store metadata for stars and deep-sky objects.

AI Assistant - Answer natural language questions using identified
objects as context.
