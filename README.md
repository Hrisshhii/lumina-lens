# 🌌 Lumina Lens

> Point. Discover. Explore the Universe.

Lumina Lens is an AI-powered astronomy application that identifies every visible star in the night sky using computer vision, astronomical catalogs, and augmented reality.

## Vision

Transform a smartphone into an intelligent window to the universe.

## Planned Features

- ⭐ Real-time star recognition
- 🌌 Every visible star is tappable
- 🛰️ Constellation detection
- 📍 Deep Sky Object recognition
- 🤖 AI astronomy assistant
- 📷 Astrophotography support
- 🪐 Offline star catalog
- 🥽 Augmented Reality overlays

## Tech Stack

- React Native
- TypeScript
- FastAPI
- PostgreSQL
- OpenCV
- Skyfield
- Astropy
- Gaia Catalog
- Hipparcos Catalog
